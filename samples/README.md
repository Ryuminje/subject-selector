# 테스트용 엑셀 표본

개발 중 화면에 직접 업로드해서 동작을 확인하는 표본 파일입니다. 코드가 이 파일들을
자동으로 읽지는 않습니다 — 브라우저에서 손으로 골라 올리는 용도입니다.

- `sample3.xlsx` — 선택과목 변경 탭의 "학생 선택 데이터 파일" 업로드에 쓰는 파일입니다
  (화면 안내 문구에도 `(sample3)`이라고 이름이 그대로 적혀 있습니다).
- 나머지는 교육과정 편제·수강신청 원본 등 단계별 업로드를 확인하려고 모아둔 파일들입니다.

> 앱이 기본으로 불러오는 표본(예: 시험 시간표 도우미의 "표본 명단으로 둘러보기")은
> 여기가 아니라 `public/`에 있습니다. 코드가 `fetch('/sample-roster-1.xlsx')`처럼
> URL로 직접 읽기 때문에 반드시 `public/`에 있어야 합니다 — 이 폴더로 옮기지 마세요.
