# 테스트용 엑셀 표본 (이 폴더에는 파일을 커밋하지 않습니다)

이 저장소는 **공개**입니다. 예전에 이 폴더에 있던 표본 엑셀(`sample.xlsx`~`sample7.xlsx`)에는
실제 학생 이름·학번이 들어 있어서 2026-10-08에 저장소에서 삭제했습니다. 다시 올라가지 않도록
`.gitignore`에 `samples/*.xlsx` 등을 올려 두었습니다.

- 개발 중 화면에 직접 올려 보는 실제 파일은 **저장소 밖**(이 컴퓨터에서는 `C:\dev\private-samples\`)에
  두고 쓰세요. 코드는 이 폴더를 자동으로 읽지 않습니다 — 브라우저에서 손으로 골라 올리는 용도입니다.
- 공개해도 되는 표본이 필요하면 이름·학번을 지어낸 가짜 데이터로 만들어 쓰세요.
- 앱이 기본으로 불러오는 가짜 표본(예: 시험 시간표 도우미의 "표본 명단으로 둘러보기")은 여기가 아니라
  `public/`에 있습니다. 코드가 `fetch('/sample-roster-1.xlsx')`처럼 URL로 직접 읽기 때문에 반드시
  `public/`에 있어야 합니다 — 이 폴더로 옮기지 마세요.
- 이력에서도 이 파일들을 지웠습니다(2026-10-09, `git filter-repo` + 강제 푸시). 다만 GitHub가 옛 커밋을
  한동안 보관하므로 지원 요청이 남아 있습니다. 자세한 내용은 `.agents/HISTORY.md`의 2026-10-09 항목을 보세요.
